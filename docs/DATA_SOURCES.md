# Data sources

Use the official [NHANES 2017–March 2020 pre-pandemic release](https://wwwn.cdc.gov/nchs/nhanes/continuousnhanes/default.aspx?Cycle=2017-2020). Merge required public components by `SEQN`, retain survey design variables, and do not pool the combined release with standalone 2017–2018.

Trial metadata use the AACT snapshot dated 2026-05-01. Obtain records from [ClinicalTrials.gov](https://clinicaltrials.gov/) or [AACT](https://aact.ctti-clinicaltrials.org/downloads). This repository redistributes neither source.
